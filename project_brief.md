# My agent: Smart Pantry Concierge

One-liner: A conversational assistant that helps users manage their pantry inventory, search recipes, and add new ingredients to their pantry catalog.

Tool coverage:
- Memory: User dietary restrictions, preferred cuisine, household size
- Tools: list_pantry_items, add_pantry_item, search_pantry_items
- Catalog/UI: Collection of pantry items (name, category, quantity, unit, expiration_days)
- Image gen: Generating visual recipe serving ideas
- Sandbox: n/a

Recommended for every project: memory, storage, tools, image generation, A2UI
